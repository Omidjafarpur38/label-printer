**Experimental, unsigned prerelease. For testing only.**

First installable build of the Label Printer Agent for Windows x64.

## Read first

- The installer is **not digitally signed**. Windows shows "Unknown publisher" and SmartScreen may warn.
  Verify the SHA-256 below before running it. Do not disable Defender or SmartScreen.
- **Physical printing: not tested.** No label printer was available. Printer model/DPI: none.
- Never connected to a production ERP.
- Installing does not pair, start, register autostart or print.

## What it does

- Pairs with one ERP over HTTPS; stores the credential with DPAPI for the current Windows user.
- Sends the ERP's printer commands unchanged, once, as a RAW document to one explicitly selected print queue.
- Keeps a durable journal; a job whose outcome is unknown is never sent again automatically.
- Per-user install, no administrator rights, no Windows Service, autostart off by default.

## Tested

- Linux and Windows: unit, fault-injection and HTTP transport tests (in-repo runner).
- Windows runner: RAW spooler against a file-backed print queue; DPAPI store; journal locking.
- Windows runner (Windows Server image): silent install, upgrade with data preserved, silent uninstall.
- Developer machine: transport and sync against the real ERP backend with PostgreSQL, synthetic data.

## Not tested

- Any physical printer.
- Windows 10/11 client editions, the interactive installer pages, SmartScreen behaviour.
- Agent with real ERP and real Windows spooler in the same run.

## Requirements

Windows x64, build 17763 or later. The .NET runtime is included. See `setup-guide.md` (installed with the
program) for setup, test pairing, printer selection, diagnostics and removal.

## Known limitations

One ERP and one printer; no printer-language detection; no inspection of printer commands; runs only while
the user is logged in; no automatic update; journal is never compacted.
