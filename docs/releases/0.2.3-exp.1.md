**Experimental, unsigned prerelease. For testing only.**

The program now announces new versions by itself and installs them only when the user approves.

## Read first

- The installer is **not digitally signed**. Windows shows "Unknown publisher" and SmartScreen may warn.
  Verify the SHA-256 below before running it. Do not disable Defender or SmartScreen.
- **Physical printing: not tested** by the author of this release.
- The window and the update flow were checked over loopback with a fake installer launcher, not with a real
  installer on a real desktop.
- This version must be installed by hand once; older versions cannot update themselves.

## What is new

- **Update notice**: a banner and an "Update" card in the window announce a newer version. Nothing is downloaded or
  installed until you press "Install and update" and confirm.
- **Signed updates**: the update description is signed with a key whose public half is built into the program; the
  installer must match the signed size and SHA-256, only newer versions are offered, redirects are not followed.
  See `docs/auto-update.md`. If this build has no key built in, the Update card says the feature is not active.
- **Upgrade re-opens the window** after a self-update (the installer's `/UPDATE=1` step).

## Tested

- Linux and Windows CI: all earlier tests plus update tests (signature, rotation, tampering, downgrade, size and
  hash mismatch, redirect, http refusal, no key, confirmation required, no address in the state).
- Windows CI runner: build, silent install, upgrade and silent uninstall.

## Not tested

- A real self-update on a real PC; any physical printer; SmartScreen; the interactive installer pages.

## Requirements and limits

Same as 0.2.2-exp.1. Updates need the owner to have created the update signing key once (`docs/auto-update.md`).
