**Experimental, unsigned prerelease. For testing only.**

Adds a control window, so that setting up and watching the agent no longer needs a command line.

## Read first

- The installer is **not digitally signed**. Windows shows "Unknown publisher" and SmartScreen may warn.
  Verify the SHA-256 below before running it. Do not disable Defender or SmartScreen.
- **Physical printing: not tested.** No label printer was available. Printer model/DPI: none.
- The control window has been tested on Linux with a development stand-in and on a Windows CI runner for
  installation only. It has **not** been seen by a person on a real Windows desktop.
- Never connected to a production ERP.

## What is new

- **Control window** (Persian, right-to-left): connect to the ERP with a pairing code, choose the printer, see
  the jobs in plain words, stop/continue sending, cancel a job that has not been sent, delete a sent job from the
  Windows queue (it then becomes *unknown*), switch autostart on or off.
- It is a local page served on `127.0.0.1` and shown by Microsoft Edge in app mode (own window, no address bar);
  Chrome or the default browser are used if Edge is missing. Protected by a per-run token, strict cookies,
  header/origin checks and a strict content policy.
- **Autostart** is now a visible installer choice, checked by default, starting without a window. Upgrades never
  switch it back on once you turned it off.
- **Single instance**: starting the program again opens the window of the running one.
- Start-menu icon, optional desktop icon, application icon.
- There is still no "send again" button. An *unknown* job is never resubmitted automatically.

## Tested

- Linux and Windows CI: all earlier tests plus 18 control-window tests (security checks, pairing, printer
  selection, pause/continue, cancel, delete from the queue, quarantine, no-credential-in-state).
- Windows CI runner: build, silent install, the program idling unconfigured with its panel reachable, refusal
  of requests without the session cookie, single instance, stop, upgrade with data and autostart choice kept,
  silent uninstall.

## Not tested

- Any physical printer.
- The window in Edge on a real desktop (layout, fonts, taskbar behaviour), Windows 10/11 client editions,
  SmartScreen, the interactive installer pages.
- Agent with a real ERP and a real Windows spooler in one run.

## Requirements and limits

Windows x64, build 17763 or later; Microsoft Edge (or Chrome) is needed for the window, otherwise the default
browser is used. Runs only while the user is logged in. One ERP and one printer; no printer-language detection;
no inspection of printer commands; no automatic update.
