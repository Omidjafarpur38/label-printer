**Experimental, unsigned prerelease. For testing only.**

Brand, readability and privacy pass over the control window.

## Read first

- The installer is **not digitally signed**. Windows shows "Unknown publisher" and SmartScreen may warn.
  Verify the SHA-256 below before running it. Do not disable Defender or SmartScreen.
- **Physical printing: not tested** by the author of this release (a printer was reported working by the owner, but
  no printer model/DPI was recorded here).
- The window was checked in headless Chromium against a stub and on a Windows CI runner for installation only. It
  has **not** been seen by a person on a real Windows desktop.
- Never connected to a production ERP by the build tests.

## What is new

- **Print report** (tab 3): a summary (waiting, in the Windows queue, printed, failed/unknown) and one clear card
  per job with state, time, copies, queue number and error code. Digits and mixed Persian/Latin text no longer
  jump around.
- **Font**: Vazirmatn (SIL OFL) is embedded, so Persian text looks the same on every PC.
- **Brand**: Flow Poshak logo in the window (light and dark variants), a new application and installer icon that
  combines the logo with a printer badge, an installer wizard image.
- **Privacy**: the server address and any port are never shown or asked for. The address is built in; the window
  sends only the pairing code and a computer name; messages and logs shown in the window are scrubbed of URLs,
  hosts and ports.
- **Hardening**: extra response headers (Permissions-Policy, COOP, CORP), `font-src 'self'`, `asInvoker` manifest.
- **Antivirus friendliness without a certificate**: version information, manifest and icon on both programs and the
  installer, no packers. See `docs/security-and-signing.md` for what a real signature needs.

## Tested

- Linux and Windows CI: all earlier tests plus privacy tests (no address in the state or page sources, built-in
  server used and failing closed, the scrubber, font/logo served under the strict policy).
- Windows CI runner: build, silent install, upgrade and silent uninstall.

## Not tested

- Any physical printer by the build; the window in Edge on a real desktop; SmartScreen; the interactive installer pages.
- Agent with a real ERP and a real Windows spooler in one run.

## Requirements and limits

Same as 0.2.1-exp.1. Connecting still needs a pairing code from the ERP, and the ERP page that creates one may not
exist yet.
