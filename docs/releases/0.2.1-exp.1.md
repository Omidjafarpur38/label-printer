**Experimental, unsigned prerelease. For testing only.**

Reorganises the control window into tabs and adds a connection guide.

## Read first

- The installer is **not digitally signed**. Windows shows "Unknown publisher" and SmartScreen may warn.
  Verify the SHA-256 below before running it. Do not disable Defender or SmartScreen.
- **Physical printing: not tested.** No label printer was available. Printer model/DPI: none.
- The window has been tested in headless Chromium against a stub and on a Windows CI runner for installation
  only. It has **not** been seen by a person on a real Windows desktop.
- Never connected to a production ERP.

## What is new

- **Tabs** in the control window: 1 Connect, 2 Printer, 3 Control and jobs, and a new Guide tab. A tick marks a
  finished step; the window opens on the first unfinished one and moves on after a successful pairing or
  printer save.
- **Fixed server address** `https://poshakerp.top` is shown instead of an input. A small "change server (for
  testing only)" link opens the field, for example to use the demo server.
- **Guide tab**: prerequisites, how to get a pairing code, how to fill each field, printer setup, a test print
  and day-to-day use. It states plainly that the ERP has no "create pairing code" button yet.
- The version string no longer renders reversed.

## Important limitation

Connecting needs a pairing code, and the ERP does not yet have a page to create one. The ERP backend for the
agent also has to be deployed and the feature switched on for the tenant. Until then the agent cannot connect
to `poshakerp.top`.

## Tested

- Linux and Windows CI: all earlier tests plus a check that the four tab panels and the guide link exist.
- Windows CI runner: build, silent install, upgrade and silent uninstall.

## Not tested

- Any physical printer.
- The window in Edge on a real desktop (layout, fonts, taskbar behaviour), SmartScreen, the interactive
  installer pages.
- Agent with a real ERP and a real Windows spooler in one run.

## Requirements and limits

Same as 0.2.0-exp.1: Windows x64, build 17763 or later; Microsoft Edge (or Chrome) for the window. Runs only
while the user is logged in. One ERP and one printer; no automatic update.
